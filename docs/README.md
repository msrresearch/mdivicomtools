# Docs

These docs are the current public reference set for the `mdivicomtools` core. The focus is the public CLI/contracts surface, not a full workflow manual.

Key topics:
- `docs/openSIDS.md` - current public draft of the session, sync, annotation, and resultbundle model (`v0.2`)
- `docs/plugin_contract.md` - plugin discovery and run interface draft (`v0.1`)
- `docs/resultbundle_runtime_integration.md` - runtime validation and handoff note for result bundles (`v0.1`)
- `docs/container_plugin_quickstart.md` - expected docker/container command shape and current backend caveats
- `docs/public_private_bridge.md` - public/private boundary and install story

Historical public snapshots:
- `docs/archive/openSIDS.md` - archived earlier public openSIDS draft (`v0.1`)

Contributor workflow:
- See `CONTRIBUTING.md` for the minimal public repo policy, release flow, and safety guardrails.
